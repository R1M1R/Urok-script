# ПайтонЛаб 7

Мобильный курс Python для 7 класса: 7 глав, уроки 21–47 (27 часов). Открывается в браузере телефона, без установки.

Сайт: https://r1m1r.github.io/Urok-script/

## Как зайти ученику

1. Открыть ссылку.
2. Написать фамилию и имя, выбрать класс (7А–7Н).
3. Идти по главам. Главы 1 и 2 открыты сразу. Следующая открывается после оценки 3 или выше за предыдущую.

Прогресс хранится в телефоне. Вставка чужого кода в задачах отключена.

## Режим учителя

Пять быстрых нажатий на значок **Py** в шапке. PIN: `2026`.

- **Открыть все главы** — снимает замки на этом телефоне.
- **Вернуть замки** — снова по порядку, с оценки 3.

## Журнал в Google Таблице

Адрес приёма уже прописан в `js/app.js` (`GOOGLE_SCRIPT_URL`). Кнопка «Отправить в журнал учителя» на экране **Итог** шлёт одну строку:

`name`, `gradeClass`, `mark`, `g1`…`g7`, `tasks`, `quizzes`, `xp`, `hints`, `tabSwitches`, `verifyCode`.

`mark` — итог за курс. `g1`…`g7` — оценки по главам. `verifyCode` (вид `PY7-……`) пересчитывается при каждом изменении результата: тот же ученик с другим числом задач получит другой код.

Чтобы принимать ответы в свою таблицу:

1. В таблице: Расширения → Apps Script.
2. Скрипт `doPost(e)` читает `JSON.parse(e.postData.contents)` и дописывает строку.
3. Развернуть как веб-приложение: доступ «все», выполнить «от моего имени».
4. Новый URL вставить в `GOOGLE_SCRIPT_URL` и залить обновление на GitHub Pages.

## План на 27 уроков

В каждой главе первая карточка теории — тот же план. Один пункт — один час. «Если успели» можно перенести, но эти задачи тоже входят в оценку.

1. **21–22.** Скрипт, `print`, комментарии, поиск ошибок.
2. **23–24.** Переменная, `input`, анкета, обмен значений.
3. **25–26.** Типы, `//`, `%`, `**`.
4. **27–28.** `import math`, корень, округление.
5. **29–33.** `if`, `elif`, `else`, `and` / `or` / `not`, вложенный `if`.
6. **34–41.** `for`, `while`, сумма, зависание, копилка, шаг `range`, `break` / `continue`, цикл в цикле.
7. **42–47.** Повторение, средний балл, максимум, банкомат, своя сумма, игра «Угадай число», касса и лестница, экран «Итог».

## Что внутри

Главы 1–3: скрипты, `input`, типы. Глава 4: `math`. Глава 5: `if`, в том числе вложенный. Глава 6: `while`, `for`, шаг `range`, `break` / `continue` и цикл внутри цикла. Глава 7: зачёт на все эти приёмы. Python выполняется в браузере. Бесконечный цикл обрывается примерно через 3 секунды.
